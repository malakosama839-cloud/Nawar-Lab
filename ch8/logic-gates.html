Logic Gates

What Is a Logic Gate?

A logic gate is a small electronic circuit (built from transistors) with one or more inputs and one output. Every input and output is a digital signal: 0 (LOW) or 1 (HIGH). The gate "decides" its output according to a fixed rule — a piece of logic. Combining just three basic gates, you can build every digital circuit that exists.

The Three Basic Gates

AND — "both or nothing"

Output is 1 only when A and B are both 1. Otherwise 0. Symbol: a D-shape.

OR — "one is enough"

Output is 1 when A or B (or both) is 1. Only 0 when both are 0. Symbol: a shield shape with a curved back.

NOT — "the opposite"

Output is the inversion of the single input: 0 in → 1 out, 1 in → 0 out. Symbol: a triangle with a small bubble (the bubble means "invert").

Memory aid: AND = series switches (both needed). OR = parallel switches (either one works). NOT = flips the answer.

Truth Tables

A truth table lists the output of a gate for every possible combination of inputs. Two inputs (A, B) give 2 × 2 = 4 rows:

ABA AND BA OR BNOT A
00001
01011
10010
11110

NOT takes one input only, so its table has just two rows: 0 → 1 and 1 → 0.

Worked example: A burglar alarm rings when the door sensor AND the motion sensor both send 1 — that is an AND gate. The same system also has a night-mode lamp that turns on when the door sensor OR the window sensor sends 1 — an OR gate. One night the door reads 1 and the window reads 0: alarm = 1 AND 0 = 0 (silent), lamp = 1 OR 0 = 1 (on).

Combining Gates

Gates can be chained: the outputs of some gates become the inputs of others. For example, feeding A and B into an AND gate, then OR-ing the result with a third input C, gives (A AND B) OR C — output 1 if C alone is 1, or if A and B are both 1. Every processor, memory chip and calculator is millions of gates combined this way.
