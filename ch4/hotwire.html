The Hot-Wire Ammeter

An ordinary moving-coil meter is useless for AC — so we measure alternating current with heat.

The Problem with Ordinary Meters on AC

A moving-coil (galvanometer-type) ammeter depends on the direction of the current: reverse the current and the pointer tries to swing backwards. House-hold AC reverses direction 100 times per second (50 Hz), so the pointer would only vibrate uselessly around zero — the average value of a sine wave over a full cycle is zero.

What we actually want to know is: which steady (DC) current would deliver the same power as this AC? That value is called the effective value (RMS value). The hot-wire ammeter reads exactly it.

Construction

  • A thin wire (AB) of a high-melting-point alloy (platinum–iridium), stretched between two terminals — the current to be measured passes through it.
  • A fine thread attached to the middle of the wire, wrapped once around a small pulley carrying the pointer.
  • A spring that keeps the thread taut and pulls the pointer back to zero when the current stops.

How It Works

The current heats the thin wire by I²R heating (Joule's law). The wire expands and sags, the thread is pulled inwards, the pulley rotates and the pointer swings across the scale. When the current stops, the wire cools and contracts and the spring returns the pointer to zero.

The clever part: the heating produced by a current is proportional to I², and squaring makes positive and negative halves identical — the heating is completely independent of the direction of the current. So the pointer settles at one steady reading no matter how fast the current alternates, and it reads the same for AC as it would for the equivalent DC. That is why the scale of a hot-wire ammeter gives the effective (RMS) value directly — and the instrument works for DC as well as AC.

Irms = Im / √2   ,   Vrms = Vm / √2for a sine wave: the effective value = peak value ÷ 1.414 (≈ 0.707 × peak)
Worked example: The voltage of the mains has a peak value Vm = 311 V. What does a hot-wire voltmeter read?
Vrms = Vm/√2 = 311 / 1.414 = 220 V — the familiar "mains voltage".
If the same supply drives a peak current Im = 2 A, the meter reads Irms = 2 / 1.414 ≈ 1.41 A.
